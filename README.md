# 雾 白 机 (WuBai Phone) ☽ ⋆ 𝖂𝖚𝖇𝖆𝖎 ⋆ ☾

一款拟真、充满氛围感的网页版（PWA）“小手机”。无需下载 App，直接在浏览器中运行。

> “我对自己说，跨过去，春天不远了。”

## ✨ 核心特性 (Features)

### 🌊 极致开屏体验
- **WebGL 真实流体力学水波纹**：基于 WebGL 与 Canvas 渲染的刮雾特效，指尖滑动即可产生真实的物理水波与雾水擦除、回雾效果。
- **自由进入**：没有时间限制，随时点击右上角的 `ENTER` 即可进入锁屏。
- **PWA 支持**：支持添加到桌面，像原生 App 一样沉浸式全屏运行。

### 📱 拟真系统交互
- **锁屏与桌面**：支持 4 位密码解锁（默认 `1234`），动态岛（Dynamic Island）UI，平滑的页面滑动与图标拖拽重排。
- **小组件系统**：内置时钟、日历、纪念日、文字卡片、明信片、拍立得、音乐盒、对话框等 8 种桌面小组件，可随意调整尺寸与位置。
- **全局状态**：状态栏时间、桌面时钟与组件实时同步。

### 💬 深度定制 AI 聊天
- **角色扮演 (Roleplay)**：支持导入角色人设（支持从 .txt / .md 导入）、世界书（背景设定）。
- **多模态与流式输出**：支持 OpenAI 格式的 API 接口，支持流式打字机效果、智能断句（通过 `|||` 分割气泡）、图文对话（配置视觉模型）。
- **朋友圈互动**：发朋友圈后，AI 角色会根据人设自动点赞、评论或回复你的评论，互动感拉满。

### 🎵 沉浸式全局音乐系统 (全新升级)
- **网易云风格滑动歌词**：丝滑跟手的拖动体验，支持物理惯性滑动。松手 3 秒后自动平滑回正至当前高亮歌词，支持带时间戳精确跟随，无时间戳自动匀速滚动。
- **三种音源支持**：支持导入本地音频、在线直链、以及直接搜索全网歌曲（基于 GD 音乐台）并抓取封面与歌词。
- **链接自愈与防断连**：在线歌曲链接过期或失效时，播放器会自动向服务器重新请求最新播放地址并续播，防止“点了没反应”。
- **智能时长校准**：无论在本地、搜索还是最近播放列表，一旦播放器读取到真实音频时长，会自动静默修正 UI 上的 `--:--` 并存入数据库。
- **全能媒体控制**：全局后台播放，且完美与桌面“音乐盒”小组件联动，支持切歌、暂停、进度拖拽。

### 📖 回忆与潮汐
- **回忆收纳**：长按聊天消息即可收藏，以“书架”与“手账便签”的形式在「回忆」App 中展示，并支持写下专属批注。
- **潮汐记录**：生理期记录与智能预测，根据周期阶段动态改变 App 色调，并给予温柔的文案陪伴。

### 🎨 高自由度美化 (美化 App)
- **全局换肤**：支持替换桌面 App 图标、锁屏与主屏壁纸。
- **自定义字体**：支持从本地（.ttf/.otf）或网络链接导入字体，全局生效。
- **主题 JSON**：支持一键导出/导入完整的主题配置（包含图标、壁纸、字体、小组件配图等），轻松和他人分享你的“雾白机”。

## 🛠️ 如何部署 (Deployment)

本项目为纯前端代码，所有数据保存在浏览器的 IndexedDB 中。无需服务器后端，直接部署到静态托管平台即可。

1. **Fork / Clone** 本仓库。
2. 将仓库部署到 **GitHub Pages**、**Vercel** 或 **Netlify**。
3. 手机浏览器打开部署后的链接，即可开始使用。
4. （推荐）在 iOS Safari 或 Android Chrome 中点击“添加到主屏幕”，以获得最佳的 PWA 沉浸式体验。

### ⚠️ 关于开屏底图 (bg.jpg) 的更换须知
如果你 Fork 后想更换开屏的背景图，请注意以下几点：
1. **文件名必须为 `bg.jpg`**：因为代码中固定读取此路径，且 Linux 服务器对大小写极其敏感（不能是 `BG.JPG` 或 `bg.jpeg`）。
2. **尺寸与大小**：为了确保低端手机的 WebGL 纹理渲染流畅，建议底图分辨率在 1080P 左右，文件大小不超过 2MB。
3. **缓存问题**：如果替换后没更新，请清除浏览器缓存或重新安装 PWA（由于 Service Worker 会拦截缓存）。

## 🔒 数据与隐私 (Privacy)
所有数据（聊天记录、好友、图片、音乐、API Key 等）**完全保存在你本地的浏览器（IndexedDB）中**，不会上传到任何服务器。清理浏览器数据会导致数据丢失，建议平时定期在浏览器中做好备份。
